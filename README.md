## 🚀 Como rodar localmente

Como o Node.js e as dependências já foram instalados, você pode rodar de qualquer uma das formas abaixo:

### Opção 1: Pelo Terminal (Prompt de Comando ou PowerShell)
Abra a pasta do projeto e execute:
```bash
npm run dev
```
ou para já abrir direto no navegador padrão:
```bash
npm start
```
O servidor local iniciará em `http://localhost:5173/`.

### Opção 2: Com 2 Cliques
Dê um duplo clique no arquivo:
- **`start.bat`**

---

## 🛠️ Scripts Disponíveis no `package.json`

- **`npm run dev`**: Inicia o servidor de desenvolvimento rápido com Vite e Hot-Reload.
- **`npm start`**: Inicia o servidor e já abre automaticamente uma aba no seu navegador.
- **`npm run build`**: Gera o pacote de produção otimizado e minificado na pasta `/dist`.
- **`npm run preview`**: Testa localmente os arquivos finais gerados pela build de produção.
